# Hands-On Labs

19 self-directed labs covering Solutions Architecture, Cloud Engineering, DevOps, SRE, security,
and FinOps, plus a dedicated [Kubernetes learning path](./kubernetes) (`K8S-01` through `K8S-18`).
See [`PROJECT_SUMMARY.md`](./PROJECT_SUMMARY.md) for how the labs connect and progress.

Each lab includes a **Project Summary** section — a concise write-up of what was built and why,
written in first person to practice articulating the design decisions out loud. These are
self-directed practice exercises, not client engagements; any "client" or "team" referenced in
that framing is a hypothetical used to give the scenario a concrete stakeholder to design for.

See the top-level [README](../README.md#labs) for the full lab index.
