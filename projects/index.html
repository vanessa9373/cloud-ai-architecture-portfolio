AWS Terraform Multi-AZ Well-Architected Personal Project

Highly Available WordPress Infrastructure on AWS

Designed a zero-single-point-of-failure WordPress architecture spanning three Availability Zones. EC2 Auto Scaling behind an Application Load Balancer handles traffic spikes; RDS Multi-AZ with automatic failover keeps the database available in under two minutes; CloudFront with S3 origin access control reduces latency globally. WAF protects against OWASP Top 10 threats, KMS encrypts data at rest, and SSM Session Manager eliminates bastion hosts.

AWS Organizations Terraform SCPs SSO Personal Project

Multi-Account AWS Landing Zone

Built an enterprise-grade governance foundation with AWS Organizations: four OUs, 10+ accounts, and eight Service Control Policies blocking root access, mandating IMDSv2, restricting regions, and preventing public S3 buckets. Transit Gateway hub-and-spoke topology isolates production and non-production environments. IAM Identity Center provides SAML 2.0 SSO, and GuardDuty with Security Hub centralizes threat findings.

Lambda API Gateway DynamoDB SQS Personal Project

Serverless Order Processing Pipeline

Designed an event-driven serverless order pipeline where API Gateway receives orders, Lambda validates and processes them, SQS decouples downstream fulfillment services, and DynamoDB stores order state. SNS sends notifications on completion or failure. CloudWatch alarms monitor Lambda errors and DLQ depth. The architecture scales to zero and incurs no idle costs.
